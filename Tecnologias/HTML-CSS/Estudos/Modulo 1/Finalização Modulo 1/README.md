# 🧠 Finalização do Módulo 1 — HTML e CSS

Depois de 18 aulas, o primeiro módulo de HTML e CSS está concluído.

Neste módulo foram estudados os principais fundamentos para começar a desenvolver páginas Web, passando pela estrutura do HTML, textos, links, listas, imagens, responsividade, áudio, vídeos e os primeiros conceitos de CSS.

Também foram trabalhadas diferentes formas de aplicar CSS, incluindo estilos inline, internos e externos, além da utilização de um mesmo arquivo CSS em várias páginas.

## 📚 Conteúdos estudados

- Estrutura básica do HTML
- Textos e títulos
- Links e âncoras
- Links internos e externos
- Links para download
- Listas
- Imagens
- Imagens responsivas
- Áudio em HTML
- Vídeos em HTML
- Vídeos incorporados com iframe
- YouTube e Vimeo
- Introdução ao CSS
- CSS inline
- CSS interno
- CSS externo
- Seletores CSS
- Sites com múltiplas páginas
- Organização e boas práticas
