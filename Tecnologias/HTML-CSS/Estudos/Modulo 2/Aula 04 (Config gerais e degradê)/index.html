Degradê com CSS

Trabalhando com gradientes e fundos no CSS

Mudando a cor do fundo da página

Antes de trabalhar com degradês, é importante entender que podemos definir uma cor de fundo utilizando a propriedade background-color.

background-color: #1976D2;

Usando background-image para degradê

Para criar um degradê, podemos utilizar a propriedade background-image.

background-image: linear-gradient(red, blue);

Usando linear-gradient()

O linear-gradient() cria uma transição de cores seguindo uma direção.

linear-gradient(to right, #101A2B, #1976D2)

Configurações globais do CSS

Quando estamos criando um projeto real, é comum utilizar configurações globais para evitar comportamentos inesperados dos elementos.

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

Fazendo um degradê mais harmônico

Nem toda combinação de cores fica agradável. Para criar um degradê mais harmônico, é interessante utilizar cores que tenham alguma relação entre si.

Deixando o fundo em degradê fixo na tela

Em alguns projetos podemos querer que o fundo permaneça fixo enquanto o conteúdo da página se movimenta.

background-attachment: fixed;

Mudando o ângulo do degradê

Além de utilizar direções como "to right", também podemos definir o ângulo do degradê utilizando graus.

linear-gradient(45deg, #101A2B, #1976D2)

Usando radial-gradient()

Diferente do linear-gradient(), o radial-gradient() cria o degradê partindo de um ponto central e se espalhando.

radial-gradient(circle, #4A90E2, #101A2B)

Personalizando ainda mais o degradê

Podemos utilizar várias cores dentro de um mesmo degradê e também definir posições específicas para essas cores.

0% → 50% → 100%

Resumo rápido

Propriedade/Função Função
background-color Define uma cor de fundo
background-image Permite utilizar imagens e gradientes
linear-gradient() Cria um degradê linear
radial-gradient() Cria um degradê radial
background-attachment Controla o comportamento do fundo durante a rolagem
deg Define o ângulo do degradê

Conclusão

Nesta aula aprendi que os degradês podem ser criados diretamente pelo CSS, sem precisar transformar o efeito em uma imagem.

O linear-gradient() permite criar transições seguindo uma direção, enquanto o radial-gradient() cria uma transição que parte de um ponto central.

Também aprendi que posso controlar o ângulo, utilizar várias cores, definir posições e até deixar o fundo fixo durante a rolagem.

DICA PARA LEMBRAR:

linear-gradient() → degradê em uma direção.
radial-gradient() → degradê partindo de um ponto central.
